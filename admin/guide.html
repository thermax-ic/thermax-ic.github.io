网站内容维护说明

管理员首次连接

  1. 打开 Pages CMS，使用有仓库管理权限的 GitHub 账号登录。
  2. 按提示安装 Pages CMS GitHub App，选择 thermax-ic 组织，仅授权 thermax-ic.github.io 仓库。
  3. 打开这个仓库，选择 main 分支；后台将读取已有配置，显示中文栏目。
  4. 在协作者管理界面添加导师邮箱。导师通过邮件里的邀请或登录链接进入。
  5. 与导师一起修改一小段文案、保存，并等官网更新，完成首次使用验证。

导师日常操作

  1. 从邀请邮件或管理入口进入后台，选择要维护的栏目。
  2. 修改对应的中文和英文内容。图片可选择已有文件，也可上传新文件。
  3. 点击 Save（保存），等待自动发布完成。官网通常需要数分钟更新，实际时间取决于 GitHub 排队。
  4. 打开官网检查。语言切换按钮可以分别核对中文和英文。

维护研究方向与配图

  1. 打开“研究方向管理”，点击现有方向进行编辑，或点击 Add / New（新增）建立新的方向。
  2. 填写中英文方向名称和介绍。正文采用可视化编辑器，可以分段、加粗、添加列表或插入图片；“研究要点”也可逐条新增、删除和拖动排序。
  3. 在“研究方向配图”中选择已有图片或上传新图片，再填写图片内容说明和图片下方说明。原理图建议选择“完整显示”，照片可以选择“填满区域”；没有配图时留空即可。
  4. 设置“排列顺序”，数字越小越靠前；关闭“在网站显示”可暂时隐藏方向，保留内容供以后继续编辑。
  5. 保存后，页面目录、方向编号、配图和搜索结果自动更新。新增方向无需填写文件名或代码。

页面顶部的引言与研究愿景在“研究方向页面介绍”中维护。本次只迁入原有三个方向及其配图，后续研究内容由编辑者人工调整。中文和英文需要分别核对；尚未填写英文时，英文页面会暂时显示已有中文。

新增成员、论文或新闻

在对应管理栏目点击 Add / New（新增），填写内容，再保存。成员与设备的地址标识使用英文小写字母、数字与连字符，例如 zhe-cheng；已有条目的标识保持不变，避免旧链接失效。成员姓名、身份与教育经历只填写已确认的信息；没有照片或简介可以留空。教育经历按从最近到最早排列，中英文逐条对应。

论文引用会按填写的原文展示。PDF 字段可选择上传文件，也可填写公开 PDF 链接；新闻月份填写 1–12。排列顺序数字较小的排在前面；论文优先按年份倒序，新闻优先按年月倒序。

图片、链接与双语

图片文件通过图片字段选择或上传。上传新照片后，确认其说明、来源及“图片是 AI 示意图”的开关与实际相符。照片位置如 50% 50% 表示居中，第二个百分比减小可把人物头部移向可见区域。链接显示文字和链接地址是独立字段；修改邮箱时应同时修改显示文字与 mailto: 开头的链接。

后台不会自动翻译。每次修改学术内容后，请核对对应中文和英文；没有提供的信息可以留空。研究方向、成员、论文、设备和新闻关闭“在网站显示”后仍保留在后台，但不会出现在官网。

保存后没有更新或需要撤销

管理员打开 自动发布记录。绿色表示发布成功；红色表示内容校验或部署失败，旧版官网继续保留。查看失败步骤中的错误提示，修正后重新保存。

小范围撤销可以把字段改回原值并保存。需要恢复大量内容时，由管理员利用仓库历史记录恢复对应文件；不要在旧版本页面中反复保存覆盖其他人的新修改。
