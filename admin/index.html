网站内容管理

在内容后台修改文字、照片、成员、论文、设备与新闻。登录后选择对应栏目，即可开始编辑。

打开内容编辑后台 →

  1. 管理员首次使用：使用 GitHub 登录，并为 thermax-ic/thermax-ic.github.io 仓库安装 Pages CMS GitHub App。
  2. 导师使用：管理员先在后台邀请导师邮箱；导师通过邮件里的登录链接进入后台。
  3. 展开 页面介绍，先选页面，再选对应区域；修改中文与英文内容，点击 Save（保存）。研究方向、成员、论文和新闻条目从对应管理栏目进入。
  4. 保存会启动自动检查与发布。等待发布完成后刷新官网，分别检查中文和英文页面。

页面介绍按区域分别保存，保存后再切换其他区域。公共名称、Logo、导航与页脚在“公共页头与页脚”中维护。研究方向、成员、论文、设备和新闻中的“在网站显示”开关控制条目是否公开。中英文需要分别核对，后台不会自动翻译学术内容。
